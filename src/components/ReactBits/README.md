# ReactBits StrokeText

`StrokeText.jsx` is based on the ReactBits component, with a CAMAC-specific shaping-aware animation path: Arabic/Persian words stay as intact SVG text runs so contextual joining is preserved, while other scripts retain per-character tracing. `StrokeText.css` and the upstream license remain included. License terms are in `LICENSE.md`.
